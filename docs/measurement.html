Measurement: angles, lines, circles, solids

The everyday measurements of school geometry, each exact: the angles of a polygon, a line written as y = mx + b, the length of a tangent, the centre and radius hidden in an equation, and the volumes and areas of solids, with π kept as a symbol.

Angles of a polygon

A polygon with nnn sides cuts into n−2n - 2n−2 triangles from one vertex, so its interior angles add to (n−2)⋅180∘(n - 2)\cdot 180^\circ(n−2)⋅180∘. A regular one has each interior angle (n−2)⋅180∘/n(n-2)\cdot180^\circ/n(n−2)⋅180∘/n, and each exterior angle 360∘/n360^\circ/n360∘/n: walking round the polygon turns you once.

angleSum(8);        // 1080 (degrees)
interiorAngle(8);   // 135
exteriorAngle(8);   // 45
interiorAngle(7);   // 900/7, exactly

Forms of a line

geo stores a line as ax+by+c=0ax + by + c = 0ax+by+c=0, which covers vertical lines too. Every line that is not vertical has a slope m=−a/bm = -a/bm=−a/b and a yyy-intercept −c/b-c/b−c/b, and can be written in slope–intercept form y=mx+by = mx + by=mx+b or in point–slope form y−y0=m(x−x0)y - y_0 = m(x - x_0)y−y0​=m(x−x0​) through any of its points.

const l = line([-2, 5], [4, -7]);
l.slope;                    // -2
l.toSlopeIntercept();       // "y = -2x + 1"
l.toPointSlope([-2, 5]);    // "y - 5 = -2(x + 2)"
slopeIntercept([0, 0], [2, 1]).text;          // "y = (1/2)x"
pointSlope([1, 2], "3/4").toSlopeIntercept(); // "y = (3/4)x + 5/4"

Tangent length

The radius to the point of tangency is perpendicular to the tangent, so from a point at distance ddd from the centre the tangent segment has length d2−r2\sqrt{d^2 - r^2}d2−r2​: the square root of the point's power with respect to the circle.

tangentLength(circle([0, 0], [5, 0]), [13, 0]);   // 12

A circle from its equation

Completing the square turns x2+y2+Dx+Ey+F=0x^2 + y^2 + Dx + Ey + F = 0x2+y2+Dx+Ey+F=0 into (x+D/2)2+(y+E/2)2=(D2+E2)/4−F(x + D/2)^2 + (y + E/2)^2 = (D^2 + E^2)/4 - F(x+D/2)2+(y+E/2)2=(D2+E2)/4−F. circleFromEquation reads the equation as text (any common factor, either side of the equals sign) or as the six coefficients of a general conic, and says so when the equation is a single point or has no points at all.

const c = circleFromEquation("x^2 + y^2 - 6x + 4y - 12 = 0");
c.center;    // (3, -2)
c.radius;    // 5
circleFromEquation("x^2 + y^2 + 1 = 0");   // refused: no real point (r² < 0)

Solids

box(a, b, c) is an exact polyhedron, so it has a volume, a surface area, faces and edges. The round solids report their measures as multiples of π\piπ: a cylinder has volume πr2h\pi r^2hπr2h and surface 2πr(r+h)2\pi r(r + h)2πr(r+h), a cone 13πr2h\tfrac13\pi r^2h31​πr2h and πr(r+s)\pi r(r + s)πr(r+s) with slant s=r2+h2s = \sqrt{r^2 + h^2}s=r2+h2​, a sphere 43πr3\tfrac43\pi r^334​πr3 and 4πr24\pi r^24πr2.

box(4, 5, 6).surfaceArea;   // 148
cylinder(3, 5).volume.text; // "45·π"
cone(3, 4).surfaceArea.text;// "24·π" (slant 5)
sphere(3).volume.text;      // "36·π"

Similar figures with scale factor kkk have areas in the ratio k2k^2k2 and volumes in the ratio k3k^3k3. similar takes kkk, or two corresponding lengths, areas or volumes, and returns all three ratios.

similar({ volumes: [8, 27] });   // { scale: 3/2, area: 9/4, volume: 27/8 }
