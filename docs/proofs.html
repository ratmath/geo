General proofs, by algebra

A check tests a theorem on one figure. A proof here covers every figure at once: the coordinates are letters, the hypotheses and the conclusion are polynomials, and the proof is a single polynomial identity that you can multiply out yourself.

Prove a theorem

From a figure to polynomials

Take Thales' theorem: an angle inscribed in a semicircle is a right angle. Put the centre at the origin and the diameter along the x-axis, from A=(−r,0)A = (-r, 0)A=(−r,0) to B=(r,0)B = (r, 0)B=(r,0). Nothing is lost by this choice of axes. The third point C=(x,y)C = (x, y)C=(x,y) is on the circle, and that is the one hypothesis:

h=x2+y2−r2=0. h = x^2 + y^2 - r^2 = 0 . h=x2+y2−r2=0.

The conclusion is that CACACA and CBCBCB are perpendicular, so their dot product vanishes:

g=(x+r)(x−r)+y⋅y=x2+y2−r2. g = (x + r)(x - r) + y \cdot y = x^2 + y^2 - r^2 . g=(x+r)(x−r)+y⋅y=x2+y2−r2.

Here g=hg = hg=h, so the conclusion follows from the hypothesis for every rrr, xxx and yyy. That one line is a complete proof of the theorem. Most theorems need more algebra, but the shape is the same.

The coordinates come in three kinds. Some are numbers, fixed by the choice of axes. Some are parameters: rrr and xxx above, free to take any value, so that the figure is a general one. The rest are unknowns, tied to the earlier coordinates by the hypotheses: yyy above. Each unknown comes with one hypothesis.

import { configuration } from "@ratmath/geo";

const T = configuration("Thales");
const O = T.at("O", 0, 0);
const r = T.parameter("r");
const A = T.at("A", r.neg(), 0);
const B = T.at("B", r, 0);
const C = T.on("C", (P) => T.onCircle(P, O, A));    // x free, y tied down by the circle
const proof = T.prove(T.rightAngle(A, C, B));
proof.proved;       // true
proof.method;       // "wu"
proof.replay();     // true: the identity was multiplied out again

What counts as a proof

Let h1,…,hrh_1, \dots, h_rh1​,…,hr​ be the hypotheses and ggg the conclusion. A proof is an identity between polynomials

d⋅gk  =  c1h1+c2h2+⋯+crhr d \cdot g^{k} \;=\; c_1 h_1 + c_2 h_2 + \dots + c_r h_r d⋅gk=c1​h1​+c2​h2​+⋯+cr​hr​

with a multiplier ddd that is not the zero polynomial. At any figure where every hih_ihi​ is zero the right side is zero, so d⋅gk=0d \cdot g^k = 0d⋅gk=0, and wherever d≠0d \neq 0d=0 that forces g=0g = 0g=0. The identity can be checked by expanding both sides. Nothing about how it was found needs to be trusted, and proof.replay() does that expansion each time it is called.

The multiplier matters. Its factors are the degenerate cases, the figures the proof does not cover: a triangle whose corners are in a line, two points that coincide, two lines that were supposed to meet but are parallel. A textbook proof assumes these away silently. Here they are computed, and proof.conditions lists them with a geometric reading where one is recognised.

import { proofs } from "@ratmath/geo";

const p = proofs.eulerLine().parts[0];         // O, G, H are collinear
String(p.identity.multiplier);                 // "b·d"   for A = (0, 0), B = (b, 0), C = (c, d)
p.identity.cofactors.map(String);              // the six cᵢ
p.conditions.map((c) => c.meaning);            // ["A, B, C are not collinear"]
p.explain();                                   // the whole proof as text

So the Euler line theorem is proved for every triangle that is not flat, which is every triangle.

Wu's method

Build the figure one point at a time, and each new unknown coordinate arrives with the hypothesis that pins it down. The hypotheses are then in triangular form: h1h_1h1​ involves the first unknown, h2h_2h2​ the first two, and so on. Wu Wen-tsün's method divides the conclusion by the hypotheses in reverse order, each time treating the hypothesis as a polynomial in the unknown it introduced.

Division by a polynomial whose leading coefficient is itself a polynomial needs pseudo-division: multiply by that leading coefficient first, so that no fractions appear.

Is⋅g=q⋅h+r,deg⁡xr<deg⁡xh, I^{s} \cdot g = q \cdot h + r, \qquad \deg_x r < \deg_x h, Is⋅g=q⋅h+r,degx​r<degx​h,

where III is the leading coefficient of hhh as a polynomial in xxx. If after dividing by every hypothesis the remainder is zero, the pieces assemble into the identity above, with ddd a product of leading coefficients. The method is fast, because it never does more than follow the construction backwards. Every theorem in the list on this page is proved this way in a few milliseconds, except Desargues' theorem, which takes about a third of a second.

When a point is given by two conditions that both involve both of its coordinates (the intersection of two lines, say), the library first eliminates one coordinate between them, again by pseudo-division, and keeps track of how the new polynomials are built from the original hypotheses, so that the final identity is still in terms of those.

The Gröbner method

The second method follows Kapur. Treat the parameters as constants, that is, work with polynomials in the unknowns whose coefficients are rational functions of the parameters. The conclusion follows from the hypotheses, for general values of the parameters, exactly when

1∈⟨ h1,…,hr, 1−t g ⟩ 1 \in \langle\, h_1, \dots, h_r,\ 1 - t\,g \,\rangle 1∈⟨h1​,…,hr​, 1−tg⟩

for a new variable ttt. (If the hypotheses hold and g=0g = 0g=0, the last generator is 1; if they hold and g≠0g \ne 0g=0, choose t=1/gt = 1/gt=1/g. So the generators have no common zero exactly when ggg vanishes wherever the hypotheses do. This is Rabinowitsch's trick, the same one that proves the Nullstellensatz.) A Gröbner basis decides the question, and its cofactors, with denominators cleared and ttt replaced by 1/g1/g1/g, are the identity. The multiplier ddd is then a polynomial in the parameters alone, so the degenerate cases are conditions on the given points only.

const w = proofs.simson({ method: "wu" });
const k = proofs.simson({ method: "groebner" });
[w.proved, k.proved];                          // [true, true]
k.conditions.map((c) => c.meaning);            // ["A, B, C are not collinear", "A ≠ C", "B ≠ C"]
[w.size.cofactorTerms, k.size.cofactorTerms];  // the two certificates differ, and both multiply out

The Gröbner method is complete where Wu's simple form is not: it finds a proof whenever the statement holds for general parameters. It is also much slower when the hypotheses are not linear in the unknowns, since it computes with fractions of polynomials. With method: "auto" (the default) Wu's method goes first; if it fails, one figure with random whole-number parameters is tried; and only if the conclusion holds at every solution of that figure is the Gröbner method run, with a time limit.

What algebra cannot see

Polynomial equations do not distinguish inside from outside or one side of a line from the other. Three consequences are worth knowing.

  • Bisectors. The condition "equal angles" describes the internal and the external bisector together. A point on a bisector at A and a bisector at B is the incentre or one of the three excentres; tritangentCenter means all four. Theorems true of all four (the third bisector passes through, the distances to the sides are equal) are proved. Theorems true only of the incentre are not, and the report says at how many of the solutions the conclusion held.
  • Second intersections. "A point on this line and on this circle" has two solutions, and if one of them is already in the figure, the algebra allows the new point to be the old one. Use otherIntersection, which asks for the second point by a linear condition. The butterfly theorem is proved when stated that way and fails when stated loosely, as it should.
  • Complex figures. The identity holds for complex coordinates too. That is usually harmless, but it means a statement can be true of all real figures and still not provable this way, if it fails for complex ones.

When no proof exists the result has proved: false and an instance: the parameters tried, the number of solutions of the hypotheses there, and at how many the conclusion holds. A statement that is simply false shows 0.

const T = configuration("a false statement");
const A = T.at("A", 0, 0), B = T.at("B", "b", 0), C = T.at("C", "c", "d");
const M = T.midpoint("M", B, C);
const no = T.prove(T.perpendicular(A, M, B, C));     // "every median is an altitude"
no.proved;          // false
no.instance;        // { parameters: { b: 14, c: 13, d: 22 }, solutions: 1, holdsAt: 0 }
