@ratmath/geo

Many geometries, each with exact coordinates

A library for exploring geometries, continuous and discrete: the Euclidean plane with constructions and checked theorems, the sphere and the hyperbolic plane, projective and finite geometries, lattices, symmetry groups and tilings.

Planned, not built yet. This site is the frame the package will grow into. The full plan is in the library roadmap, and the RatMath Shelf page lists what exists across all the libraries.

What it will cover

  • The Euclidean plane: constructions, triangle centres, transformations, theorems checked exactly.
  • Exact computational geometry and lattice geometry (Pick's theorem, convex hulls), and other metrics.
  • Spherical geometry and the models of the hyperbolic plane.
  • Projective planes and finite geometries.
  • Solids, symmetry groups, friezes, wallpaper groups and tilings.
  • General proofs of theorems by elimination.

How the docs will be laid out

Like every library on the Shelf: this overview, an Explore page for trying things without writing code, a Reference listing every function, and one page per topic that explains the usage and the mathematics. Every page ends with a box of code you can edit and run.
