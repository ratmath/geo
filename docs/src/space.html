Vectors, lines and planes in space

Three-dimensional coordinates, exact: the dot and cross products, lengths that stay square roots, angles, projections, and the lines and planes of multivariable calculus with their equations, distances and intersections.

Vectors

vector(x, y, z) takes rationals or exact numbers such as "sqrt(2)". The dot product \(\mathbf u\cdot\mathbf v = u_1v_1 + u_2v_2 + u_3v_3\) is \(|\mathbf u||\mathbf v|\cos\theta\); the cross product

\[ \mathbf u\times\mathbf v = (u_2v_3 - u_3v_2,\ u_3v_1 - u_1v_3,\ u_1v_2 - u_2v_1) \]

is perpendicular to both, with length \(|\mathbf u||\mathbf v|\sin\theta\), the area of the parallelogram they span. The scalar triple product \(\mathbf u\cdot(\mathbf v\times\mathbf w)\) is the signed volume of the parallelepiped.

const u = vector(1, 2, -2), v = vector(3, 0, 4);
u.dot(v);          // -5
u.cross(v);        // (8, -10, -6)
u.norm;            // 3
u.angle(v).cos;    // -1/3
v.projectOnto([0, 0, 1]);              // (0, 0, 4)
tripleProduct([4, 0, 0], [0, 5, 0], [0, 0, 6]);   // 120

Planes

A plane is \(\mathbf n\cdot\mathbf x = d\) for a normal \(\mathbf n\). Through three points \(P, Q, R\) the normal is \((Q - P)\times(R - P)\), and three points on one line are refused. The equation prints with whole coefficients and no common factor. The distance from a point is \(|\mathbf n\cdot\mathbf p - d|/|\mathbf n|\), reached at the foot of the perpendicular.

const P = plane([1, 0, 2], [2, 1, 0], [0, 3, 1]);
P.equation;            // "5x + 3y + 4z = 13"
P.distance([0, 0, 0]); // 13/√50, an exact square root
P.foot([0, 0, 0]);     // (13/10, 39/50, 26/25)
plane([0, 0, 0], { normal: [0, 0, 1] });   // z = 0
plane({ coefficients: [1, 1, 1, 3] });     // x + y + z = 3

Lines and intersections

line3(p, q) is the line \(\mathbf p + t(\mathbf q - \mathbf p)\). A plane meets a line in a point (or contains it, or misses it), and two planes that are not parallel meet in a line whose direction is the cross product of their normals.

const Q = plane({ coefficients: [1, -1, 0, 1] });
plane({ coefficients: [1, 1, 1, 3] }).meet(Q);    // a Line3: point + t·(1, 1, -2)
P.meet(line3([0, 0, 0], [1, 1, 1]));              // (13/12, 13/12, 13/12)
