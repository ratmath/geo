Measurement: angles, lines, circles, solids

The everyday measurements of school geometry, each exact: the angles of a polygon, a line written as y = mx + b, the length of a tangent, the centre and radius hidden in an equation, and the volumes and areas of solids, with π kept as a symbol.

Angles of a polygon

A polygon with \(n\) sides cuts into \(n - 2\) triangles from one vertex, so its interior angles add to \((n - 2)\cdot 180^\circ\). A regular one has each interior angle \((n-2)\cdot180^\circ/n\), and each exterior angle \(360^\circ/n\): walking round the polygon turns you once.

angleSum(8);        // 1080 (degrees)
interiorAngle(8);   // 135
exteriorAngle(8);   // 45
interiorAngle(7);   // 900/7, exactly

Forms of a line

geo stores a line as \(ax + by + c = 0\), which covers vertical lines too. Every line that is not vertical has a slope \(m = -a/b\) and a \(y\)-intercept \(-c/b\), and can be written in slope–intercept form \(y = mx + b\) or in point–slope form \(y - y_0 = m(x - x_0)\) through any of its points.

const l = line([-2, 5], [4, -7]);
l.slope;                    // -2
l.toSlopeIntercept();       // "y = -2x + 1"
l.toPointSlope([-2, 5]);    // "y - 5 = -2(x + 2)"
slopeIntercept([0, 0], [2, 1]).text;          // "y = (1/2)x"
pointSlope([1, 2], "3/4").toSlopeIntercept(); // "y = (3/4)x + 5/4"

Tangent length

The radius to the point of tangency is perpendicular to the tangent, so from a point at distance \(d\) from the centre the tangent segment has length \(\sqrt{d^2 - r^2}\): the square root of the point's power with respect to the circle.

tangentLength(circle([0, 0], [5, 0]), [13, 0]);   // 12

A circle from its equation

Completing the square turns \(x^2 + y^2 + Dx + Ey + F = 0\) into \((x + D/2)^2 + (y + E/2)^2 = (D^2 + E^2)/4 - F\). circleFromEquation reads the equation as text (any common factor, either side of the equals sign) or as the six coefficients of a general conic, and says so when the equation is a single point or has no points at all.

const c = circleFromEquation("x^2 + y^2 - 6x + 4y - 12 = 0");
c.center;    // (3, -2)
c.radius;    // 5
circleFromEquation("x^2 + y^2 + 1 = 0");   // refused: no real point (r² < 0)

Solids

box(a, b, c) is an exact polyhedron, so it has a volume, a surface area, faces and edges. The round solids report their measures as multiples of \(\pi\): a cylinder has volume \(\pi r^2h\) and surface \(2\pi r(r + h)\), a cone \(\tfrac13\pi r^2h\) and \(\pi r(r + s)\) with slant \(s = \sqrt{r^2 + h^2}\), a sphere \(\tfrac43\pi r^3\) and \(4\pi r^2\).

box(4, 5, 6).surfaceArea;   // 148
cylinder(3, 5).volume.text; // "45·π"
cone(3, 4).surfaceArea.text;// "24·π" (slant 5)
sphere(3).volume.text;      // "36·π"

Similar figures with scale factor \(k\) have areas in the ratio \(k^2\) and volumes in the ratio \(k^3\). similar takes \(k\), or two corresponding lengths, areas or volumes, and returns all three ratios.

similar({ volumes: [8, 27] });   // { scale: 3/2, area: 9/4, volume: 27/8 }
