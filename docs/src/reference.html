Reference

Everything in the library

Every export of @ratmath/geo, with what it takes and what it returns. A point goes in as [x, y] or a Point; a coordinate is a whole number, a fraction or decimal string, a string such as "sqrt(3)/2", a Core Rational or an algebraic number. A JavaScript number that is not whole is refused.

Numbers

ExportWhat it does
num(x)An exact number from any of the forms above: a Rational when rational, otherwise an algebraic number.
NArithmetic on those numbers: add, sub, mul, div, neg, sq, sqrt, sign, isZero, cmp, eq, abs, min, max, sum, isRational, toNumber, text(a, digits), enclose(a, bits), cosPi(q), sinPi(q).
GeoErrorWhat the library throws, with a code: inexact, bad-number, bad-figure, division, sqrt and others.

General proofs

NameWhat it is
configuration(name)A figure in coordinates, to state a theorem about. Its methods make points, give the polynomials of geometric properties, and prove.
T.at(name, x, y), T.free(name), T.parameter(name)A point with given coordinates (numbers, parameter names, or expressions); a point with two free coordinates; a free number.
T.on(name, P => condition, { free }), T.where(name, P => [c1, c2]), T.unknown(name, v => condition)A point with one free coordinate and one condition; a point fixed by two conditions; a number fixed by an equation.
T.midpoint, intersection, foot, reflection, parallelogram, circumcenter, orthocenter, centroid, tritangentCenter, onLine, onCircumcircle, otherIntersectionConstructions. Lines are pairs of points: T.intersection("P", [A, B], [C, D]).
T.collinear, parallel, perpendicular, equidistant, equalLength, onCircle, concyclic, concurrent, rightAngle, equalAngle, tangent, isMidpoint, equalPredicates: the polynomial (GeoExpr) that vanishes when the property holds.
T.distance2, area2, dot, cross, number; e.add, sub, mul, neg, powQuantities, and arithmetic on expressions.
T.prove(conclusion, { method, timeLimit, maxPairs, instance })A Proof. method is "wu", "groebner" or "auto". A list of conclusions gives a Proof with parts.
T.instance(conclusion), T.describe(), T.parameters, T.unknowns, T.hypotheses, T.pointsOne figure tried: { parameters, solutions, holdsAt }; the figure as text; the variables and hypotheses.
proof.proved, proof.method, proof.replay()Whether an identity was found and multiplied out; by which method; multiply it out again.
proof.identity{ ring, multiplier, power, cofactors, hypotheses, conclusion } with multiplier · conclusion^power = Σ cofactors[i] · hypotheses[i], as polynomials of @ratmath/structures.
proof.conditionsThe degenerate cases: [{ polynomial, text, meaning }]. The proof covers every figure at which none vanishes.
proof.explain({ cofactors }), proof.parts, proof.instance, proof.size, proof.msThe proof as text; one proof per conclusion; the figure tried when not proved; size of the certificate; time taken.
provable, proofs.<id>(options), proofs.all(options), proofs.setup(id)The classical theorems proved in general: thales, pythagoras, isosceles, midline, medians, altitudes, bisectors, eulerLine, ninePointCircle, orthocentreReflection, tritangent, varignon, parallelogram, inscribedAngle, chords, simson, butterfly, pappus, desargues, gaussLine, napoleon.

See General proofs.
