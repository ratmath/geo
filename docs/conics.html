Conic sections

Give conicProperties any equation Ax2+Bxy+Cy2+Dx+Ey+F=0Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0Ax2+Bxy+Cy2+Dx+Ey+F=0 and it says what the curve is and finds everything a course asks about it: the centre or vertex, the axes, vertices, foci, eccentricity, directrices and asymptotes. The answers are exact, square roots and all, even when the conic is turned by an angle that is not a nice one.

Centre and axes

An ellipse or hyperbola has a centre, where the gradient of the left side vanishes: a 2 × 2 linear system. Moving the centre to the origin leaves λ1X2+λ2Y2+F′=0\lambda_1X^2 + \lambda_2Y^2 + F' = 0λ1​X2+λ2​Y2+F′=0 in the directions of the eigenvectors of (AB/2B/2C)\begin{pmatrix} A & B/2 \\ B/2 & C\end{pmatrix}(AB/2​B/2C​), with F′=Δ/(AC−B2/4)F' = \Delta/(AC - B^2/4)F′=Δ/(AC−B2/4). Then a2=−F′/λa^2 = -F'/\lambdaa2=−F′/λ along the axis whose λ\lambdaλ is smaller in size (for a hyperbola, the one whose λ\lambdaλ has the sign of −F′-F'−F′), and c2=a2∓b2c^2 = a^2 \mp b^2c2=a2∓b2. With B=0B = 0B=0 the axes are the coordinate directions and everything is rational or one square root; with B≠0B \ne 0B=0 the eigenvalues are square roots and the directions are algebraic numbers, still exact.

const e = conicProperties("9x^2 + 4y^2 - 36 = 0");
e.type;          // "ellipse"
e.a; e.b;        // 3, 2
e.foci;          // [(0, √5), (0, −√5)]
e.eccentricity;  // √5/3

const h = conicProperties("x^2/16 - y^2/9 = 1");
h.asymptotes;    // ["3·x − 4·y = 0", "3·x + 4·y = 0"]
h.directrices;   // ["5·x − 16 = 0", "5·x + 16 = 0"]: x = ±a²/c

conicProperties("x^2 + xy + y^2 = 3").axes.major;   // x + y = 0, with a² = 6, b² = 2

Parabolas

When B2=4ACB^2 = 4ACB2=4AC the quadratic part is a perfect square and one eigenvalue is 0; its eigenvector is the direction of the axis. In coordinates along and across the axis the equation becomes (w−w0)2=4p(s−s0)(w - w_0)^2 = 4p(s - s_0)(w−w0​)2=4p(s−s0​): the vertex is (s0,w0)(s_0, w_0)(s0​,w0​), the focus is ppp along the axis from it, and the directrix is ppp the other way.

const p = conicProperties("x^2 - 4y - 2x + 9 = 0");
p.vertex;      // (1, 2)
p.focus;       // (1, 3)
p.directrix;   // y − 1 = 0
conicProperties("x^2 - 2xy + y^2 - 4x - 4y = 0").focus;   // (1/2, 1/2): a parabola turned 45°
